# ساختار خطاها و پاسخ‌ها

تمامی پاسخ‌های API سواپین دارای یک فیلد مشترک به نام `ok` هستند که وضعیت موفقیت درخواست را نشان می‌دهد.

---

## ✅ پاسخ‌های موفق (Success)
در صورت موفقیت، کد وضعیت HTTP در بازه `200` تا `299` خواهد بود و `ok: true` برگردانده می‌شود.

```json
{
  "ok": true,
  "...": "داده‌های مربوط به هر اندپوینت"
}
```

---

## ❌ ساختار خطاها (Errors)
در صورت بروز خطا، `ok: false` بوده و فیلدهای `error` (کد خطا) و `message` (توضیح فارسی) ارائه می‌شوند.

```json
{
  "ok": false,
  "error": "error_code",
  "message": "توضیح خطا به زبان فارسی"
}
```

### کدهای خطای رایج:

| کد HTTP | کد خطا (error) | توضیح |
| :--- | :--- | :--- |
| `401` | `invalid_api_key` | کلید API ارسال نشده یا نامعتبر است. |
| `403` | `forbidden` | دسترسی به این منبع برای فروشگاه شما مجاز نیست. |
| `404` | `not_found` | منبع مورد نظر (مثلاً محصول با این شناسه) یافت نشد. |
| `405` | `method_not_allowed` | متد HTTP استفاده شده برای این مسیر مجاز نیست. |
| `422` | `validation` | داده‌های ارسالی معتبر نیستند (فیلد `fields` شامل جزئیات است). |
| `429` | `too_many_requests` | تعداد درخواست‌های شما بیش از حد مجاز است. |
| `500` | `internal_error` | خطای داخلی سرور. |

---

## 🔍 خطاهای اعتبارسنجی (Validation Errors)
هنگامی که خطای `validation` (کد ۴۲۲) رخ می‌دهد، یک فیلد اضافی به نام `fields` بازگردانده می‌شود که شامل نام فیلد و دلیل خطا برای هر مورد است.

**نمونه:**
```json
{
  "ok": false,
  "error": "validation",
  "message": "برخی فیلدها معتبر نیستند.",
  "fields": {
    "category_id": "دسته‌بندی انتخاب شده معتبر نیست.",
    "latitude": "مختصات جغرافیایی باید داخل محدوده ایران باشد."
  }
}
```

---

## 🛡️ نکات امنیتی
- هرگز کلید API خود را در کدهای سمت کلاینت (مانند مرورگر) قرار ندهید.
- در صورت لو رفتن کلید، بلافاصله از پنل مدیریت اقدام به غیرفعال‌سازی و تولید کلید جدید کنید.
- تمامی ارتباطات باید بر بستر پروتکل امن **HTTPS** انجام شود.
